# ETL-парсер для создания базы знаний о продуктах

Этот проект представляет собой ETL-скрипт (Extract, Transform, Load) для сбора данных о продуктах с сайта `bast.ru`. Скрипт извлекает информацию о товарах через публичный API, парсит их веб-страницы (включая динамический контент) и PDF-руководства пользователя. В результате работы генерируются структурированные Markdown-файлы (`.md`), предназначенные для использования в качестве базы знаний для ИИ-ассистента или RAG-системы.

## Архитектура и структура проекта

Проект организован с прицелом на дальнейшее масштабирование (добавление БД, Telegram-бота и т.д.) и разделен на логические модули:

- **`bast_parser.py`**: Точка входа в приложение парсера. Может быть запущена как самостоятельный скрипт или импортирована как модуль (`run_parser()`) в другие части проекта.
- **`src/bast_parser/config.py`**: Конфигурационные параметры (URL, пути, лимиты, настройки параллелизма).
- **`src/bast_parser/models/`**: Pydantic-модели для строгой валидации и типизации JSON-ответов от API.
- **`src/bast_parser/api_client/`**: Модуль для взаимодействия с каталогом товаров API `bast.ru`.
- **`src/bast_parser/parser/`**: 
    - `html_parser.py`: Модуль для парсинга веб-страниц товаров. Использует headless-браузер для обхода защиты от парсинга и рендеринга динамического JavaScript-контента (вкладок).
    - `pdf_parser.py`: Модуль для извлечения сырого текста из PDF-инструкций.
- **`src/bast_parser/builder/`**: Модуль для сборки итогового Markdown-файла на основе собранных данных по шаблону.
- **`knowledge_base/`**: Директория (создается автоматически), в которую сохраняются результирующие `.md` файлы (названные по артикулу товара).

## Технологический стек

- **Python 3.11+**
- **httpx**: Асинхронный HTTP-клиент для выполнения быстрых запросов.
- **Playwright**: Асинхронное управление headless-браузером Chromium для парсинга сложных сайтов с клиентским рендерингом (SPA/AJAX) и обхода базовых anti-bot систем.
- **BeautifulSoup4**: Для очистки HTML-дерева от мусора (скрипты, стили, шапки, футеры) и точечного поиска контента по CSS-селекторам.
- **html2text**: Для финальной трансформации очищенного HTML в человекочитаемый Markdown.
- **PyMuPDF**: Для надежного и быстрого извлечения текста из PDF-документов.
- **Pydantic v2**: Для валидации структур данных.
- **aiofiles**: Для асинхронного сохранения файлов на диск.
- **tqdm**: Для красивого отображения прогресс-бара в консоли.

## Особенности реализации
- **Обход блокировок**: Используются специальные флаги Chromium (`--disable-blink-features=AutomationControlled`, подмена User-Agent) и последовательные запросы (`MAX_CONCURRENT_TASKS=1`) для предотвращения блокировок со стороны сервера `bast.ru` (ошибки `502 Bad Gateway`, `net::ERR_TIMED_OUT`, `Target Closed`).
- **Парсинг динамических вкладок**: Скрипт не просто скачивает HTML, а ожидает выполнения JavaScript-прелоадеров на сайте (скрытие надписи "Загрузка..."), чтобы извлечь реальный текст описания и ТТХ из вкладок продукта.

## Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <repository_url>
    cd <repository_directory>
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python -m venv .venv
    source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
    ```

3.  **Установите Python-зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Установите браузеры для Playwright:**
    ```bash
    playwright install chromium
    ```

5.  **Запустите парсер:**
    ```bash
    python bast_parser.py
    ```

Процесс может занять длительное время (в зависимости от размера каталога), так как запросы выполняются последовательно для стабильности. Логи работы пишутся в консоль и в файл `parser.log`. После завершения работы скрипта все сгенерированные файлы будут находиться в папке `knowledge_base`.
